- 新增产品级 canonical 输入：`LaunchIntent`

  - `raw_text`

  - 有外部副作用
  - 长时运行
  - 需要 review
  - 生成 evidence
  - 触发 delivery fallback

### 2. Electron 控制面重构

  - `designSystem.ts`：颜色、字体、间距、圆角、状态色、阴影、动效 tokens
  - `layout.ts` 或同级模块：shell 栅格、窄宽度退化规则、抽屉宽度、导航宽度
  - `App.tsx` 只保留页面装配和状态逻辑

  - 左导航 `264-288px`
  - 中央主工作区
  - 右侧详情抽屉 `360-420px`
- `Overview` 固定改成运营工作面，不再强调 metric card 网格：
  - 顶部只保留轻量 `status strip`
  - 主体优先显示 `high-priority work items / recent failures / pack health`
  - metrics 变成次级信息，不占首页主视觉
- `Runs` 与 `Work Items` 统一为列表优先、抽屉驱动：
  - 一行一个对象
  - 主标题、次级元数据、状态 badge、可见下一动作
  - 打开后统一进入右抽屉，不做全页跳转

  - 提升列表、细线、信息密度和 mono 数据层存在感

## Summary
- 设计结论：这不是多个平级产品并排摆着，而是一个 `Agent OS`，外加若干专用工作面。
- `hermes-agent` 是唯一 `Agent Core（云侧）`，负责 `session / memory / skills / scheduler / delivery / approvals / eval`。
- `longclaw-agent-os` 是唯一默认 home，也是 phase 1 的主工作台。它负责总控、证据、复核、失败兜底、通知和 operator actions，不负责重浏览器执行。
- `weclaw` 是主输入和异步 inbox，不是主工作台。
- `due-diligence-core / 影刀替代 sandbox` 是 phase 1 云端必选执行平面，以远程 `Domain Pack` 运行。
- `Signals` 保持完整独立引擎和专业分析能力，但在产品信息架构里降为“金融深度工作面”，不是第二个默认首页。
- `Obsidian` 只接 reviewed knowledge，不接 raw logs、不接 delivery fallback。
- `Chanless` phase 1 保留 adapter 契约，但降为可选入口，不进入主旅程、主导航、主文案。

### 2. 关键用户流
- 默认任务流：
  - `weclaw ingress -> hermes routing/session -> domain pack run -> Electron summary/work item -> optional deep work -> reviewed promotion -> Obsidian`
- 金融任务流：
  - 用户从微信提需求后，先在 `Electron` 看到 summary、状态和动作。
  - 只有需要图表、回测、结构深挖时才进入 `Signals`。
- 尽调任务流：
  - `due-diligence-core` 云端执行浏览器任务。
  - `Electron` 展示 `Recent Runs / Manual Review Queue / Repair Cases / Site Health`。
  - 证据与复核在 `Electron` 完成，reviewed 输出再晋升到 `Obsidian`。
- 失败送达流：
  - 微信窗口失效时，不等待微信恢复。
  - 默认落入 `Electron Work Items / Runs / local notification`。
  - 不把未审核结果直接写入 `Obsidian`。

### 3. 设计和实现约束
- 先补一个最小 `DESIGN.md`，再做正式控制面 UI。
- 最小设计系统必须写死：
  - 字体与颜色角色
  - 信息密度原则
  - 状态色语义
  - 卡片允许出现的条件
  - 导航层级
- Beta 适配策略固定为 `desktop-first`：
  - 要定义窄窗口退化规则
  - 要定义键盘导航和焦点顺序
  - 要定义 screen-reader landmarks
  - 状态不能只靠颜色表达
- `Electron` 的默认布局固定为：
  - 左侧导航
  - 中央主工作区
  - 右侧详情抽屉
  - 队列、证据、动作优先于装饰性统计卡
