  - 指标不允许来自 UI fallback；没有验证就是“未验证”。
- 单因子验证按 Alphalens 思路补齐：
  - T+1/T+5/T+10/T+20、胜率、MFE/MAE。
  - IC、Rank IC、分位数组收益、long-short spread、行业/概念分组表现、turnover、失败样本。

- 可复现边界按 Lean 思路固化：
  - 每次验证固定数据版本、交易日历、时间边界、成本、滑点、股票池、benchmark。
  - 美股隔夜到 A 股次日必须明确 as-of 边界，避免未来函数。
- 生命周期按 vn.py 思路：
  - `idea -> draft -> specified -> validated -> observable -> published -> disabled`。
  - 只有 `published + live_enabled + approved` 才能进入 `strategy_snapshot`，继续走现有 [ai_factor_factory.py](/Users/zhangqilong/github代码仓库/Signals/signals/strategy/ai_factor_factory.py:45) 的盘前池桥接。
- QUANTAXIS 借鉴点落在本地数据/账户/模拟：
