### 5. Signals 深页固定内容
- `Signals` 页面固定 4 个区块：
  - `Recent Runs`
  - `Review Runs`
  - `Backtest Backlog`
  - `Connector Health`
- `SignalsPack` 需要补出深度控制面数据：
  - 最近 `review/backtest/index/intraday` runs
  - `backtest summary`：`total / evaluated / pending`
  - `pending backlog preview`：取前 N 条 pending records
  - `connector health`：`tushare / futu / weclaw notify / runner`
- `work items` 映射规则固定：
  - 最近 20 条 run 中任何 `failed` run -> `warning`
  - `backtest pending > 0` -> `warning`
  - `backtest pending > 100` -> `critical`
  - `tushare_token` 缺失或 runner 不存在 -> `critical`
  - `weclaw_enabled = false` -> `info`
- Beta 可变操作固定为：
  - 触发 `review` run
  - 触发 `backtest` run
  - 打开 output/stdout artifact
  - 对已有 backtest result 执行 `push_report`
- 不为 Signals 硬造 due-diligence 风格的 `manual review queue` 或 `repair case`。
